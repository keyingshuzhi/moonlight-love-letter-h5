# Moonlight Love Letter H5

一个以「月光情书」为主题的浪漫互动 H5 页面。

项目采用原生 **HTML + CSS + JavaScript** 实现，不依赖前端框架和第三方运行时，包含星空粒子、花瓣、烟花、银河、月亮、文字打字机、音乐播放以及多章节互动告白流程，可直接在浏览器中运行，也方便部署到 GitHub Pages 等静态托管平台。

> 当前版本由原单文件 H5 拆分为 `HTML / CSS / JavaScript` 三部分。拆分仅调整代码文件组织方式，不改变原页面的视觉效果、动画逻辑、交互流程和文案内容。

## 🚀 本地运行

项目没有构建步骤，下载后即可运行。

### 方法一：直接打开

直接使用浏览器打开：

```text
index.html
```

即可查看页面。

页面会在打开时立即尝试播放背景音乐。部分浏览器可能会拦截带声音的自动播放；若被拦截，可点击右上角的音乐按钮开启。若本地直接打开受到资源访问限制，推荐使用本地 HTTP 服务。

### 方法二：Python 启动本地服务

如果已经安装 Python，可以在项目目录执行：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

### 方法三：VS Code Live Server

也可以使用 VS Code 的 Live Server 等静态服务器工具运行项目。

## 🎵 背景音乐

当前 HTML 中的音乐资源路径为：

```text
music/music.wav
```

因此本地运行时，需要按照下面的目录结构放置音乐：

```text
music/
└── music.wav
```

如果需要替换音乐，无需修改代码。将自己的 WAV 音乐文件重命名为 `music.wav`，并放入 `music/` 目录即可。当前 `index.html` 中固定引用：

```html
<audio id="bgm" src="music/music.wav" loop preload="auto" autoplay playsinline></audio>
```

后续只需要替换 `music/music.wav` 文件本身，并保持文件名为 `music.wav` 即可。



## 💌 页面流程

当前页面按照情书叙事方式划分为多个章节：

```text
加载页面
   ↓
CHAPTER 01 · 遇见
   ↓
CHAPTER 02 · 靠近
   ↓
CHAPTER 03 · 心动
   ↓
星光 / 爱心 / 名字 / LOVE / 银河 / 玫瑰动画
   ↓
CHAPTER 04 · 告白
   ↓
最终页面
```

其中「心动」章节包含项目主要的动态视觉效果。

## 📝 自定义名字

在第三章节点击：

```text
设置她/他的名字
```

页面会弹出输入框。

输入名字或昵称后，JavaScript 会根据 Canvas 文字像素生成对应的粒子目标点，并让星光粒子组成输入的名字。

当前代码会对输入长度进行限制，以避免过长文本影响粒子显示效果。

## 🧩 Canvas 图层

页面使用多个 Canvas 图层分别处理不同视觉效果：

```text
stars
   ↓
particles
   ↓
climax
   ↓
fireworks
   ↓
roseFx
   ↓
HTML / SVG 内容
```

不同动画效果独立绘制，避免所有视觉逻辑集中在同一个 Canvas 中。

## 📱 响应式设计

页面已经针对较小屏幕进行了适配。

主要通过：

```css
@media(max-width:640px)
```

调整：

- 卡片内边距
- 页面高度
- 月亮尺寸
- 场景高度
- 音乐按钮显示方式

因此可以同时用于桌面浏览器和移动浏览器。
